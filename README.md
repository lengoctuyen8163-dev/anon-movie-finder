# 🎬 Movie Finder

A clean movie search interface built using HTML, CSS, and JavaScript.

## 🚀 Features
- Search movies instantly
- Responsive grid layout
- Hover card animation
- Lightweight frontend project

## 🛠 Tech Stack
- HTML
- CSS
- JavaScript

## ▶️ How to Run
1. Download project files
2. Open `index.html`
3. Search for a movie
